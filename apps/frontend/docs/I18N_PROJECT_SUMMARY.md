## 🚀 使用方法

### 启动应用
```bash
cd /Users/sangreal/Documents/GitHub/Auto-Claude/apps
npm run dev
```

### 切换语言
1. 打开应用
2. 点击 **⚙️ 设置** (侧边栏底部)
3. 选择 **"Paths"** 标签
4. 在 **"Language / 语言"** 下拉菜单中选择语言
5. 界面立即更新

### 验证汉化
```bash
cd apps/frontend

# 验证配置
node scripts/verify-i18n.cjs

# 查看进度
node scripts/batch-i18n-analyze.cjs
```
