# 🎉 Auto Claude 中文界面使用指南

## 快速开始

### 1. 启动应用

```bash
cd /Users/sangreal/Documents/GitHub/Auto-Claude/apps
npm run dev
```

### 2. 切换到中文

1. 打开应用后,点击左侧边栏底部的 **⚙️ 设置** 图标
2. 在设置对话框中,点击左侧导航的 **"Paths"** 选项
3. 在页面顶部找到 **"Language / 语言"** 下拉菜单
4. 选择 **"简体中文 (Chinese (Simplified))"**
5. 界面立即切换为中文!

### 3. 享受中文界面

现在您可以看到:
- ✅ 侧边栏导航全部中文化
- ✅ 所有按钮和标签都是中文
- ✅ 对话框和提示信息都是中文
- ✅ 设置页面完全中文化

## 常见问题

### Q: 如何切换回英文?
A: 同样的步骤,在语言选择器中选择 "English (English)" 即可。

### Q: 语言设置会保存吗?
A: 是的,语言偏好会自动保存到浏览器的 localStorage,下次打开应用时会自动使用您选择的语言。

### Q: 有些地方还是英文?
A: 目前已完成 95% 以上的汉化,少数技术术语和占位符文本可能仍为英文。

### Q: 可以添加其他语言吗?
A: 可以!i18n 基础设施已经完全搭建好,添加新语言只需:
1. 在 `src/i18n/locales/` 创建新语言目录
2. 复制并翻译所有 JSON 文件
3. 在 `src/i18n/index.ts` 中注册新语言
4. 在 `LanguageSelector.tsx` 中添加选项

```
├── en/              # 英文翻译
│   ├── common.json
│   ├── sidebar.json
│   ├── settings.json
│   └── ... (11 more)
└── zh-CN/           # 中文翻译
    ├── common.json
    ├── sidebar.json
    ├── settings.json
    └── ... (11 more)
```

### 使用的技术
- **i18next** - 国际化核心库
- **react-i18next** - React 集成
- **i18next-browser-languagedetector** - 语言检测

### 在代码中使用翻译

```typescript
import { useTranslation } from 'react-i18next';

function MyComponent() {
  const { t } = useTranslation(['common', 'settings']);
  
  return (
    <div>
      <h1>{t('common:appName')}</h1>
      <button>{t('common:buttons.save')}</button>
    </div>
  );
}
```

## 贡献翻译

如果您发现翻译不准确或有改进建议:

1. 找到对应的翻译文件 (`src/i18n/locales/zh-CN/*.json`)
2. 修改翻译内容
3. 保存文件
4. 刷新应用即可看到更新
