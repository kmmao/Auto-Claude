## 🚀 如何使用

### 切换到中文
1. 启动应用: `npm run dev`
2. 点击 **⚙️ 设置**
3. 选择 **"Paths"** 标签
4. 在 **"Language / 语言"** 下拉菜单选择 **"简体中文"**
5. 界面立即切换为中文!

### 验证汉化
```bash
cd apps/frontend
node scripts/verify-i18n.cjs
```
